# МедиаПрофи - контент-план

Одностраничный прототип рабочего кабинета для SMM-агентства. Приложение помогает вести клиентов, план публикаций, статусы согласования и календарь контента без серверной части.

## Что внутри

- панель с ключевыми метриками по клиентам и публикациям;
- таблица клиентов с фильтрацией и добавлением новых записей;
- канбан контент-плана: черновик, согласование, запланировано, опубликовано;
- форма создания заявки на публикацию;
- календарный вид публикаций за месяц.

## Технологии

- HTML5;
- CSS3 без внешних UI-библиотек;
- Vanilla JavaScript;
- демо-данные хранятся прямо в `index.html`.

## Запуск

Проект не требует сборки и сервера.

```bash
git clone https://github.com/Qeca/mediaprofi.git
cd mediaprofi
open index.html
```

На Linux вместо `open` можно открыть файл через браузер вручную.

## Статус проекта

Это frontend-прототип: он показывает пользовательские сценарии и интерфейс, но не сохраняет данные между перезагрузками страницы. Следующий шаг для production-версии - вынести данные в backend API и подключить авторизацию.
